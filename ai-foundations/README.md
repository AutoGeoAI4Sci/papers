# AI Foundations / AI 基础

This directory will curate the most durable AI, machine-learning, and computer-vision papers that provide reusable conceptual or technical foundations. It is for papers that change how later work represents, learns from, or reasons over data, not merely papers that report a strong benchmark result.

此目录将收录最具持久价值的 AI、机器学习与计算机视觉论文。入选论文应提供可复用的概念或技术基础，改变后续工作如何表征、学习或推理数据，而不只是报告一次较强的基准结果。

## Inclusion Criteria / 收录标准

- Introduces a durable model family, training principle, representation, or evaluation paradigm.
- Has clear primary-paper provenance and, when available, an official implementation or project page.
- Remains useful for the repository's long-term GeoAI, 3D vision-language, or spatial-intelligence agenda.
